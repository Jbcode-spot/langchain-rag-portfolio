# 🚀 Enterprise Document RAG & AI Engineering Portfolio

A production-ready pipeline for processing complex documents, evaluating LLM parameters, and executing semantic search workflows using LangChain and Python.

## 🛠️ Tech Stack
* **Orchestration:** LangChain, LCEL
* **LLM Integration:** OpenAI (GPT-4o-mini), Custom Endpoints
* **Data & Analytics:** Pandas, NumPy, Regex
* **Vector Storage:** ChromaDB
* **Version Control:** Git & GitHub
